foley.agent.refine

refine_query — one event query → 2–4 paraphrases for multi-query retrieval.

Retrieval quality is sensitive to phrasing (report 05 §2.2): several phrasings of the same intent raise recall. v1 emits a multi-query list that search_sounds() runs and RRF-merges (CLAP text-embedding mean-pool fusion is a later drop-in behind this same seam). refine_query is also the re-retrieval lever in the verify→refine loop, steered by a failure hint.

Two impls behind the Refiner seam: the deterministic KeywordRefiner (default + CI fake) and the LLM-backed AnthropicRefiner (foley[agent]; anthropic imported lazily inside the method only, so import foley stays dol-only).

class foley.agent.refine.KeywordRefiner[source]

Deterministic template-expansion refiner — the default and CI fake.

Expands a query into n distinct paraphrases via fixed descriptor templates; a verify-failure hint nudges one extra variant. No RNG, no anthropic — same query → identical paraphrase list.

refine(query: str, *, n: int = 3, hint: str | None = None) → list[str][source]

Return up to n distinct paraphrases of query (the first is query).

Parameters:

  • query – The event query to expand.

  • n – How many paraphrases to return (2–4 is typical).

  • hint – Optional verify-failure reason to steer re-retrieval.
