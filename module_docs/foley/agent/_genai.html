foley.agent._genai

Shared GenAI-span recorder for the SELECT LLM rungs (decompose / refine / judge).

One small helper so the three tool wrappers record gen_ai.* span attributes the same way (DRY), without a tools ↔ decompose/refine/verify import cycle. It indexes the foley.obs.trace.GENAI SSOT dict — the semconv strings are never re-hardcoded here. The deterministic fakes pass response=None so this is a no-op for them: obs never records synthetic token usage, staying truthful.

foley.agent._genai.DEFAULT_AGENT_MODEL = 'claude-opus-4-8'

The Anthropic model every real SELECT LLM rung calls (see the foley[agent] extra).

foley.agent._genai.record_genai(span, *, request_model: str, response) → None[source]

Set gen_ai.* attributes on span from an Anthropic Message response.

No-op when span or response is None — the fakes pass response=None, so a fake-path find() records no LLM usage (obs stays truthful).

Parameters:

  • span – A recorder span handle (set_attribute); None when unrecorded.

  • request_model – The model id requested (e.g. 'claude-opus-4-8').

  • response – The Anthropic Message (.model / .usage / .stop_reason), or None on the fake path.
