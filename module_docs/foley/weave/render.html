foley.weave.render

The render — a PURE, deterministic projection of the timeline into audio (report 06 §6.4).

render(timeline, library) is a pure function of (narration, timeline, library, master): it aligns (once, cached), resolves each item’s anchor, mixes each layer bus (per-item DSP via the ApplyStrategy seam), ducks the ambience/music beds under speech, sums the buses, and masters to the timeline’s MasterProfile. Re-running after an edit reproduces exactly that change and nothing else.

An opt-in RenderCache memoises each layer’s pre-duck bus by a content hash of its items, so an incremental re-render recomputes only the changed layer(s) yet is byte-identical to a full render (ducking and mastering are always recomputed deterministically). The two shipped ApplyStrategy impls are FullRender (default, full DSP) and PlaceOnly (dry declicked placement); diff-preview / transition are reserved behind the same seam.

This module also owns the timeline export adapters: a pure-stdlib CMX3600 to_edl() (always available) and a lazy to_otio() (foley[weave]); export() prefers OTIO and falls back to EDL so export always succeeds.

class foley.weave.render.FullRender[source]

Default ApplyStrategy — the full per-item DSP chain (report 06 §3-4).

fit-duration (loop/trim) → distance → reverb send → constant-power pan → declick → gain (base layer level + item gain_db) → overlay at the resolved onset.

class foley.weave.render.PlaceOnly[source]

Dry ApplyStrategy — declicked placement, no gain/pan/distance/reverb.

The fast preview / DSP-free fallback path: fit-duration → declick → overlay at the resolved onset, at unity gain.

foley.weave.render.RENDER_LAYERS: tuple[Layer, ...] = (Layer.sfx_fg, Layer.ambience, Layer.stinger, Layer.music)

The non-voice layers the render mixes, in sum order (voice is the 0 dB anchor).

foley.weave.render.load_clip_mono(library, ref: str, *, sr: int) → ndarray[source]

Load ref from library as a mono working array at sr.

Accepts a foley.index.SoundLibrary (via .array) or a plain mapping yielding an ndarray, raw bytes, or a (samples, orig_sr) tuple — so the render is testable with a trivial dict library. Shared by render() and the WEAVE façade’s narration-binding view, so it carries no underscore.

foley.weave.render.render(timeline: SoundDesignTimeline, library, *, sr: int = 48000, transcript: str | None = None, aligner: ApplyStrategy | None = None, apply_strategy: ApplyStrategy | None = None, cache: RenderCache | None = None) → RenderResult[source]

Render timeline against library into a mastered mix (PURE, deterministic).

Parameters:

  • timeline – The sound-design timeline (sparse or hydrated). narration_ref must resolve in library; master carries the loudness target.

  • library – A foley.index.SoundLibrary (or a mapping of ref → audio).

  • sr – Working/render sample rate in Hz.

  • transcript – Narration transcript for alignment when timeline.word_timeline is empty (else alignment is skipped — the cached timeline is the seed).

  • aligner – The Aligner (default: WhisperX if foley[align] installed, else the deterministic fake).

  • apply_strategy – The per-item ApplyStrategy (default FullRender).

  • cache – An optional RenderCache for byte-identical incremental re-render (only changed layers recompute).

Returns:

A RenderResult — the mastered stereo mix, the hydrated timeline (with word_timeline cached), and the MasterReport.

foley.weave.render.to_edl(timeline: SoundDesignTimeline, *, title: str = 'foley SFX') → str[source]

Export timeline as a pure-stdlib CMX3600 EDL (deterministic, pinned ids).

A lightweight interchange for DAWs; each enabled, placed item is one event with its clip name as the source comment. Always available (no dependency).

foley.weave.render.to_otio(timeline: SoundDesignTimeline, *, rate: int = 25) → str[source]

Export timeline as an OpenTimelineIO JSON string (lazy foley[weave]).

One track per non-voice layer; each enabled, placed item is a clip with an external media reference (by clip_ref) — non-destructive, minimal-viable fidelity (tracks/clips/onsets; effects/markers are a later slice).

Raises:

RuntimeError – If opentimelineio is not installed.
